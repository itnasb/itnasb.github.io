Summary

I wrote this Python project to enhance my understanding of the mechanics behind how dictionary-based password cracking tools work at a basic level and to strengthen my scripting skills, translating that understanding into working code. The script accepts a user-selected hash type, a dictionary file of candidate passwords, and a file of hashes to crack. It then hashes each candidate password and compares the result against the supplied hash values, returning any matches it finds.

How It Works

The implementation models the core workflow of a dictionary attack. A candidate password is read from the wordlist, hashed with the selected algorithm, and then compared against each target hash in the supplied hash file. This process repeats until the wordlist has been exhausted. The script currently supports MD5, SHA-1, SHA-224, SHA-256, and SHA-512 via Python’s hashlib library.

Design Decisions

  • The wordlist is processed one line at a time instead of being loaded into memory all at once.
  • This keeps memory usage low and makes the script more practical for large dictionaries.
  • The hash file pointer is reset after each pass so every candidate password is compared against the full set of target hashes.
  • The implementation prioritizes understanding the cracking workflow over performance optimizations such as parallel processing or indexed hash lookups.

Future Improvements

Some basic input validation is already present, such as restricting supported hash type values, but there is still room to improve file validation, argument handling, and comparison logic. Professional tools like Hashcat rely heavily on acceleration via GPU parallelism to performing large numbers of hash computations simultaneously. I would like to experiment with GPU acceleration via one of the available python libraries.

def process(hashes, wordlist, htype):
    hashtypes = []
    # hashalgorithms allows to choose hash type from command line and use hashlib
    # chosen by selecting 0-4 as first option passed to program
    hashalgorithms = [hashlib.md5, hashlib.sha1, hashlib.sha224, hashlib.sha256, hashlib.sha512]
    hashtype = int(htype)
    result = []
    hashed = ""

    for wordsrow in wordlist: # runs through each word in wordlist then compares hashed value to user provided hashes
        for hashrow in hashes:
            hashed = hashalgorithms[hashtype](wordsrow.encode()).hexdigest() #hashes word from wordlist and stores hash
            if hashed in hashrow: # compares hashed word to list of hashes provided
                #appends the matching password and hash to list for printing later
                result.append([hashed, wordsrow])   # could use rstrip() to remove \n chars, but if password has blank
                                                    # space, would remove that too
        hashes.seek(0)          #seeks the start of the provided hashes file

    return result
