Automating Nuclear Compliance Documentation

Visual Basic for Applications VBA Automation Regulatory Documentation

Summary

This VBA script automates the creation of narrative responses by analyzing values across two spreadsheets and assembling standardized text in a results worksheet. It evaluates category indicators in a reference table, groups related rows by identifier, and generates a natural-language paragraph in a column on the second spreadsheet for inclusion in a regulator submission.

The goal of the automation was to reduce repetitive manual review and drafting work. By mapping category codes to predefined response templates, the macro could generate consistent narrative summaries while still flagging cases that required human input.

How It Works

The macro processes rows from a reference worksheet and compares values across columns to determine how each item should be summarized. Records are grouped by a shared identifier so that multiple rows related to the same item can be evaluated together rather than handled independently.

For each group, the script scans the category column for specific letter indicators and records their presence in an internal array. After the scan is complete, it evaluates the combination of indicators and builds a response paragraph by concatenating predefined text segments. The generated text is then written to the corresponding row in the results worksheet along with the associated item identifier. Single-row entries are processed immediately, while grouped entries are aggregated and evaluated together to produce the final output.

Limitation in This Version

A helper function used in later revisions is also absent here. As a result, the generated paragraphs were not grammatically polished and required someone to review the finished document and improve the grammar manually. 


'This VBA macro reviews rows in a source worksheet, groups related entries by a shared identifier,
'and writes summary text to an output worksheet based on category flags in the source data.
'
'This is an illustrative rewrite inspired by an earlier script. It
'has been intentionally generalized and does not include later improvements.
'
'Known limitation in this version:
' grammar in output needs work
' error handling needed


Sub BuildSummaryText()

Dim FirstRow As Long
Dim LastRow As Long
Dim SourceSheet As String
Dim OutputSheet As String

Dim statusTextPrimary As String
Dim statusTextSecondary As String
Dim reviewText1 As String
Dim statusParagraphPrimary As String
Dim statusParagraphSecondary As String
Dim flagArray(2)

statusParagraphPrimary = vbNewLine & "Primary summary paragraph placeholder"
statusParagraphSecondary = vbNewLine & "Secondary summary paragraph placeholder"

statusTextPrimary = "Primary status applies"
statusTextSecondary = "Secondary status applies"
reviewText1 = " REVIEW TYPE 1 PRESENT: MANUAL CHECK REQUIRED"

SourceSheet = "SourceData"
OutputSheet = "OutputData"
FirstRow = 2
LastRow = Worksheets(SourceSheet).Cells(Worksheets(SourceSheet).Rows.Count, "A").End(xlUp).Row

Worksheets(SourceSheet).Activate
ActiveSheet.Range("A1:K8000").Sort Key1:=Range("H1"), Order1:=xlAscending, Header:=xlYes

Dim t As Long

For t = FirstRow To LastRow

    If Worksheets(SourceSheet).Cells(t, 7) <> Worksheets(SourceSheet).Cells(t + 1, 7) And Worksheets(SourceSheet).Cells(t, 3) <> "" Then
        'Single-row group
        If InStr(Worksheets(SourceSheet).Cells(t, 10), "A") Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextPrimary & statusParagraphPrimary
            Worksheets(OutputSheet).Cells(t, 1) = Worksheets(SourceSheet).Cells(t, 7)

        ElseIf InStr(Worksheets(SourceSheet).Cells(t, 10), "B") Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextSecondary & statusParagraphSecondary
            Worksheets(OutputSheet).Cells(t, 1) = Worksheets(SourceSheet).Cells(t, 7)

        ElseIf Worksheets(SourceSheet).Cells(t, 10) = "E" Then
            Worksheets(OutputSheet).Cells(t, 5) = reviewText1
            Worksheets(OutputSheet).Cells(t, 1) = Worksheets(SourceSheet).Cells(t, 7)
        End If

    Else
        'Multi-row group
        flagArray(0) = "Z"
        flagArray(1) = "Z"
        flagArray(2) = "Z"

        Do While Worksheets(SourceSheet).Cells(t, 7) = Worksheets(SourceSheet).Cells(t + 1, 7) And Worksheets(SourceSheet).Cells(t, 3) <> ""

            If InStr(Worksheets(SourceSheet).Cells(t, 10), "A") Then
                flagArray(0) = "A"

            ElseIf InStr(Worksheets(SourceSheet).Cells(t, 10), "B") Then
                flagArray(1) = "B"

            ElseIf InStr(Worksheets(SourceSheet).Cells(t, 10), "E") Then
                flagArray(2) = "E"
            End If

            t = t + 1
        Loop

        'Evaluate the final matching row in the group.
        If InStr(Worksheets(SourceSheet).Cells(t, 10), "A") Then
            flagArray(0) = "A"

        ElseIf InStr(Worksheets(SourceSheet).Cells(t, 10), "B") Then
            flagArray(1) = "B"

        ElseIf InStr(Worksheets(SourceSheet).Cells(t, 10), "E") Then
            flagArray(2) = "E"
        End If

        Worksheets(OutputSheet).Cells(t, 1) = Worksheets(SourceSheet).Cells(t, 7)

        If flagArray(0) = "A" And flagArray(1) = "Z" And flagArray(2) = "Z" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextPrimary & statusParagraphPrimary

        ElseIf flagArray(0) = "A" And flagArray(1) = "B" And flagArray(2) = "Z" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextPrimary & statusParagraphPrimary & vbNewLine & statusTextSecondary & statusParagraphSecondary

        ElseIf flagArray(0) = "A" And flagArray(1) = "B" And flagArray(2) = "E" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextPrimary & statusParagraphPrimary & vbNewLine & statusTextSecondary & statusParagraphSecondary & vbNewLine & reviewText1

        ElseIf flagArray(0) = "A" And flagArray(1) = "Z" And flagArray(2) = "E" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextPrimary & statusParagraphPrimary & vbNewLine & reviewText1

        ElseIf flagArray(0) = "Z" And flagArray(1) = "B" And flagArray(2) = "Z" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextSecondary & statusParagraphSecondary

        ElseIf flagArray(0) = "Z" And flagArray(1) = "B" And flagArray(2) = "E" Then
            Worksheets(OutputSheet).Cells(t, 5) = statusTextSecondary & statusParagraphSecondary & vbNewLine & reviewText1

        ElseIf flagArray(0) = "Z" And flagArray(1) = "Z" And flagArray(2) = "E" Then
            Worksheets(OutputSheet).Cells(t, 5) = reviewText1
        End If
    End If

Next t

Worksheets(OutputSheet).Activate
ActiveSheet.Range("A1:G8000").Sort Key1:=Range("A1"), Order1:=xlAscending, Header:=xlYes

End Sub
